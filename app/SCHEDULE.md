# Розклад занять

Розклад розміщено в «Мій кабінет» (`/account`). Завуч і адміністратор можуть додавати, редагувати та видаляти заняття через клітинки таблиці. Дисципліна має бути призначена групі. Викладач не може мати два заняття на одну дату й пару.

Студент бачить свою групу, куратор — свої групи, викладач — групи своїх дисциплін. Завуч, директор і адміністратор бачать усі групи. Користувач без призначеної навчальної ролі бачить повідомлення про відсутність груп.

## Пари

На сторінці `/schedule/pairs` можна додавати пари та окремо змінювати час у будні (понеділок–п’ятниця) й вихідні (субота–неділя). Час завершення має бути пізніше початку, інтервали різних пар не мають перетинатися. Зміни часу діють для всіх дат, включно з минулими.

Погоджені таблиці: `pairs` і `schedule`. Міграція `Version20261020090000` створює структуру; `Version20261020090100` додає п’ять пар: 08:30–10:30, 10:30–12:30, 12:30–14:30, 14:30–16:30, 16:30–18:30. Початковий час однаковий для буднів і вихідних.

## Календар

Діапазон дат включає обидві межі, максимум — 366 днів. До семи днів включно розклад перегортається по одному дню, понад тиждень і до календарного місяця — по тижнях, понад місяць — по місяцях. У місячному календарі натискання дати відкриває її таблицю нижче. Неповні тижні й місяці обмежуються фільтром. Поточний діапазон зберігається після редагування заняття. Дата за замовчуванням визначається в часовому поясі Europe/Kyiv.

## Перевірка та застосування

Виконувати з кореня репозиторію в налаштованому Docker-середовищі:

```bash
docker compose exec -T app php vendor/bin/phpunit
docker compose exec -T app php bin/console lint:twig templates
docker compose exec -T app php bin/console doctrine:migrations:status
docker compose exec -T app php bin/console doctrine:migrations:migrate --dry-run
docker compose exec -T app php bin/console doctrine:migrations:migrate --no-interaction
docker compose exec -T app php bin/console cache:clear
```

Для production після оновлення ассетів також потрібен `php bin/console asset-map:compile`. Нові стилі розкладу підключені окремим CSS-файлом; збірка Tailwind для них не потрібна.

Відкат створення таблиць видаляє розклад і налаштування пар. Для окремого відкату початкових даних міграція видаляє лише незмінені пари без занять.
