# Розклад занять

Розклад розміщено в «Мій кабінет» (`/account`). Завуч і адміністратор можуть додавати, редагувати та видаляти заняття через клітинки таблиці. Дисципліна має бути призначена групі. Викладач не може мати два заняття на одну дату й пару.

Студент бачить свою групу, куратор — свої групи, викладач — групи своїх дисциплін. Завуч, директор і адміністратор бачать усі групи. Користувач без призначеної навчальної ролі бачить повідомлення про відсутність груп.

## Сторінка «Розклад»

Сторінка `/schedule` доступна викладачу, завучу, директору й адміністратору з головного меню. Викладач бачить лише заняття своїх дисциплін і пов’язані групи; директор переглядає всі групи без редагування. За замовчуванням показано поточний тиждень від понеділка до неділі з переходами на сусідні тижні. Фільтри дозволяють вибрати початкову й кінцеву дати проведення занять, дисципліну та групу; кнопка скидання повертає поточний тиждень і доступні групи та дисципліни.

Для вибраного періоду до календарного місяця включно сторінка перегортається по тижнях. Неповні тижні обмежуються фільтром дат. Для довшого періоду збережено місячний календар із вибором дня; максимальний період — 366 днів. Фільтри зберігаються під час перегортання, додавання, редагування й видалення занять.

Для завуча й адміністратора порожня клітинка відкриває створення заняття, заповнена — зміну дисципліни або видалення. Вони не можуть призначати теми. Якщо дисципліна вибрана у фільтрі та призначена групі, вона автоматично підставляється в нове заняття. Заняття інших дисциплін позначаються як зайняті клітинки. Нових таблиць і міграцій для цієї сторінки не потрібно.

## Пари

На сторінці `/schedule/pairs` можна додавати пари та окремо змінювати час у будні (понеділок–п’ятниця) й вихідні (субота–неділя). Час завершення має бути пізніше початку, інтервали різних пар не мають перетинатися. Зміни часу діють для всіх дат, включно з минулими.

Додавання та редагування пари відкриваються в модальному вікні. Його також можна відкрити натисканням заголовка пари безпосередньо в календарі. У вікні змінюються номер пари та час для буднів і вихідних; помилки залишаються всередині вікна. Після збереження календар або список пар оновлюється зі збереженням поточних фільтрів. Закриття доступне через хрестик, «Скасувати», Escape і натискання поза вікном. Доступ мають завуч і адміністратор.

Погоджені таблиці: `pairs` і `schedule`. Міграція `Version20261020090000` створює структуру; `Version20261020090100` додає п’ять пар: 08:30–10:30, 10:30–12:30, 12:30–14:30, 14:30–16:30, 16:30–18:30. Початковий час однаковий для буднів і вихідних.

## Календар

Діапазон дат включає обидві межі, максимум — 366 днів. До семи днів включно розклад перегортається по одному дню, понад тиждень і до календарного місяця — по тижнях, понад місяць — по місяцях. У місячному календарі натискання дати відкриває її таблицю нижче. Неповні тижні й місяці обмежуються фільтром. Поточний діапазон зберігається після редагування заняття. Дата за замовчуванням визначається в часовому поясі Europe/Kyiv.

## Розклад дисципліни та теми

На `/teacher/disciplines/{id}` викладач переглядає свою дисципліну, а завуч і адміністратор — будь-яку. Редагувати дисципліну та її прив’язку до груп можуть лише завуч і адміністратор. Для завуча додано пункт «Дисципліни» в головному меню.

На сторінці виводяться заняття поточних пов’язаних груп, упорядковані за датою, номером пари та назвою групи, по 20 на сторінку. Таблиця містить дату, день тижня, групу, номер пари, відповідний час для будня або вихідного і вибрану тему.

Завуч і адміністратор додають теми в каталозі на сторінці дисципліни. Призначає, змінює або знімає тему конкретного заняття лише його викладач: натискання заняття відкриває модальне вікно з єдиним полем «Тема заняття». Сервер відхиляє теми іншої дисципліни та спроби змінити інші поля заняття. Викладач не може створювати чи видаляти заняття, змінювати їхні дату, групу, пару або дисципліну. Адміністративні ролі не отримують права призначати теми через успадковану роль викладача.

Вибрана тема відображається в календарях `/schedule` і `/account` для викладача, завуча, директора та адміністратора. Після збереження в модальному вікні календар оновлюється, зберігаючи фільтри. Якщо завуч або адміністратор змінює дисципліну заняття, попередня тема очищується; при збереженні тієї самої дисципліни тема зберігається. Застаріла форма викладача не може призначити тему після зміни дисципліни заняття. Тема залишається необов’язковою.

Міграція `Version20261108100000` створює погоджену таблицю `lessons` для каталогу тем і додає `topic_id` до `schedule`. Її потрібно застосувати перед використанням оновлених сторінок. Відкат прибирає каталог і прив’язки тем, зберігаючи самі заняття.

## Перевірка та застосування

Виконувати з кореня репозиторію в налаштованому Docker-середовищі:

```bash
docker compose exec -T app php vendor/bin/phpunit
docker compose exec -T app php bin/console lint:twig templates
docker compose exec -T app php bin/console doctrine:migrations:status
docker compose exec -T app php bin/console doctrine:migrations:migrate --dry-run
docker compose exec -T app php bin/console doctrine:migrations:migrate --no-interaction
docker compose exec -T app php bin/console cache:clear
```

Для production після оновлення ассетів також потрібен `php bin/console asset-map:compile`. Нові стилі розкладу підключені окремим CSS-файлом; збірка Tailwind для них не потрібна.

Відкат створення таблиць видаляє розклад і налаштування пар. Для окремого відкату початкових даних міграція видаляє лише незмінені пари без занять.
