# Правила роботи з проєктом

## Назви таблиць бази даних

- Перед додаванням будь-якої нової таблиці спочатку запитай у користувача її назву та дочекайся відповіді.
- Не обирай назву таблиці самостійно. Якщо користувач уже явно вказав назву для поточного завдання, використовуй її без повторного запитання.
- Узгоджуй назву до написання Doctrine-мапінгу, генерації або написання міграції та виконання SQL для створення таблиці. Правило також стосується таблиць зв’язків та службових таблиць, які створюють бібліотеки або генератори.
